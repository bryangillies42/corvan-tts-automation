# Novo personagem

Este diretório é um ponto de partida para um Saved Object independente.

Preencha a ficha, os eventos do runtime, a UI e os assets antes de mudar o
perfil de `scaffold` para `active` no registro. Não copie regras ou valores de
outro personagem sem uma decisão explícita do dono da ficha.

O scaffold começa com `uiContract: generic`, sem moldura obrigatória. Adicione
ao menos a arte física do `Custom_Tile` antes do primeiro build. Use
`panel-board` somente se o personagem realmente precisar do contrato visual
de moldura e geometria rígida do Corvan.
