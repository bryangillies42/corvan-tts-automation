# Arcane Test

Fixture técnica do build multi-personagem. Possui ficha, recursos, ação e
geometria próprios para provar que o pipeline não depende do modelo do Corvan.
Não é uma personagem publicável.

O asset `assets/panel-board.png` é deliberadamente próprio da fixture e é
incorporado por URL raw com fingerprint. Assim, o Saved Object gerado pode ser
importado no TTS para o teste simultâneo com o Corvan sem depender de URLs
fictícias.
